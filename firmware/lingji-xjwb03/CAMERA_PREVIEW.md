# 灵犀摄像头本机预览

> 历史方案说明：2026-10-30 已切换为 [千问全模态直连](QWEN_DIRECT.md)，不再运行本文下方的灵机云 Agent + 视觉摘要注入链路。当前使用 `./lingji.sh omni`。本文保留用于回退和历史排查。

当前灵机板已烧录摄像头、云端语音和 Wi‑Fi 桥接固件。BF3901 官方帧校验通过，可抓取 240×320 JPEG。`camera_web.py` 在本机 `127.0.0.1:8765` 提供预览页；当前推荐用 [Wi‑Fi 模式](WIFI_BRIDGE.md)取图。无线供电测试中，连续取图会使语音在数次视觉回答后失去响应，因此 Wi‑Fi 模式现已改为按需取图：普通对话期间只轮询轻量状态，不请求 JPEG。

在本目录运行：

```bash
./lingji.sh preview-wifi
```

然后打开 <http://127.0.0.1:8765/>。“获取当前画面”只从板子抓一帧，不调用模型；“描述当前画面”会在缓存过期时重新取图，只把这一帧发给 `.env.local` 配置的千问模型；“描述并用喇叭播报”会再由板子逐字播出最终短答，详见 [VISION_VOICE_BRIDGE.md](VISION_VOICE_BRIDGE.md)。页面显示最近一次取到的画面和拍摄时间，旧画面会标为“上次画面”。API Key 只留在本机服务端，不传给浏览器。关闭终端中的服务按 `Ctrl+C`。

最新版也支持说出唤醒词后直接提出画面相关问题。待机时页面的“语音状态”显示云端麦克风上行关闭；唤醒后的最终语音转写才交给千问判断是否需要画面。视觉问题触发一次新画面采集与图像模型调用；普通问题仍由灵犀对话处理。语音触发依赖本机页面服务持续运行。

2026-10-26 实测：页面持续显示不同的新帧。“描述当前画面”按钮只在网页显示千问结果；“描述并让灵犀语音回应”按钮已把一次千问摘要排入语音 Agent，用户确认听到相关回答，并且语音追问正常。两个按钮都不触发机器人动作。

板上当前是**摄像头、云端语音与 Wi‑Fi 桥接合并固件**。完整 16 MB Flash 备份仍保存在本机被 Git 忽略的 `backups/`。需要 USB 串口诊断时，可改用 `./lingji.sh preview /dev/cu.usbmodem...`；重新烧录前先停止预览服务。
