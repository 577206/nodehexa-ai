# 灵犀摄像头本机预览

当前灵机板已烧录摄像头与云端语音合并固件。BF3901 官方帧校验通过，连续抓到新的 240×320 JPEG。`camera_web.py` 在本机 `127.0.0.1:8765` 提供预览页，持续读取串口并更新图像。受 115200 baud 串口和 JPEG Base64 传输限制，属于实时快照预览，不是高帧率视频。

在本目录运行：

```bash
./lingji.sh preview /dev/cu.usbmodem5CE41521261
```

然后打开 <http://127.0.0.1:8765/>。页面中的“描述当前画面”按钮只在点击时把当时的一帧发给 `.env.local` 配置的千问模型，并显示自然语言描述；“描述并让灵犀语音回应”会先检查板端桥接功能，再将短摘要交给云端语音 Agent，详见 [VISION_VOICE_BRIDGE.md](VISION_VOICE_BRIDGE.md)。页面持续预览本身不会调用模型。API Key 只留在本机服务端，不传给浏览器。关闭终端中的预览服务按 `Ctrl+C`，页面会显示服务断开。摄像头断线或帧过期时，页面显示错误并禁用按钮，服务会尝试重新连接串口。

最新版也支持说出唤醒词后直接提出画面相关问题。待机时页面的“语音状态”显示云端麦克风上行关闭；唤醒后的最终语音转写才交给千问判断是否需要画面。视觉问题才会调用图像模型；普通问题仍由灵犀对话处理。语音触发依赖本机预览服务持续运行。

2026-10-26 实测：页面持续显示不同的新帧。“描述当前画面”按钮只在网页显示千问结果；“描述并让灵犀语音回应”按钮已把一次千问摘要排入语音 Agent，用户确认听到相关回答，并且语音追问正常。两个按钮都不触发机器人动作。

板上当前是**摄像头与云端语音合并固件**。完整 16 MB Flash 备份仍保存在本机被 Git 忽略的 `backups/`；页面预览服务启动时会占用串口，重新烧录前先停止服务。
