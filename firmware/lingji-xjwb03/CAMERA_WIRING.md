# BF3901 摄像头接线（XJWB03 + 官方 2×5 转接板）

比赛配件图中的镜头模组是 **BF3901、24 针 FPC**。先将 FPC 插到配套摄像头转接板，再从转接板的信号引脚接到 XJWB03；不要将裸 FPC 直接插到 XJWB03 排针。插拔前拔掉 USB 和外部电源。FPC 的朝向按官方 [正面实拍图](sdk/doc/6-摄像头转接板/转接板正面实拍图.jpg) 和连接器触点确认，不要强插。

官方 SDK 附有[转接板引脚图](sdk/doc/6-摄像头转接板/转接板引脚图.png)，**该图是背面视角**。如果像实物照片那样将摄像头正面（镜头、FPC 座、晶振）朝向自己，镜头在上、2×5 排针在下，那么插针从左到右是：

```text
             摄像头正面、镜头在上
        左       →       →       →       右
靠镜头的一排   VCC     SDA     VSYNC   HREF    D1
靠插针尖端一排 GND     SCL     PWDN    D0      PCLK
```

已有的 2×5 整体插头可能遮住两排针。先拔下插头确认正反面；重插时记录哪一排对应靠镜头的一排。**线色没有统一定义，不凭红/黑/黄色判断信号或电源。** 最好用万用表通断档从排针逐个追到线束另一端，再贴标签。若连接器不能可靠辨别每一孔，就用 8 根单独的母头杜邦线接所需的 8 针。2×5 整体插头只插转接板，不能直接套到 XJWB03 两侧的任意 2×5 排针上；两板的针脚顺序不同。

官方 SDK 当前按 1-bit SPI 模式接收摄像头数据，模组丝印仍使用 DVP 信号名。按 `sdk/apps/main/peripheral/bsp_camera.h` 接线：

| 正面视角转接板位置 | 信号 | XJWB03 主板排针 | 说明 |
| --- | --- | --- | --- |
| 上排第 1 孔 | VCC | 3V3 | **只能接 3.3 V，不能接 5 V** |
| 下排第 1 孔 | GND | GND | 两板共地 |
| 上排第 2 孔 | SDA | P21 / GPIO21 | 传感器配置 I²C 数据 |
| 下排第 2 孔 | SCL | P47 / GPIO47 | 传感器配置 I²C 时钟 |
| 上排第 3 孔 | VSYNC | P4 / GPIO4 | 驱动把它用作 SPI CS |
| 下排第 3 孔 | PWDN | P41 / GPIO41 | 摄像头电源控制 |
| 下排第 4 孔 | D0 | P8 / GPIO8 | SPI DATA0 |
| 下排第 5 孔 | PCLK | P13 / GPIO13 | 驱动把它用作 SPI SCLK |
| 上排第 4 孔 | HREF | 不接 | 当前 1-bit SPI 驱动不用 |
| 上排第 5 孔 | D1 | 不接 | 当前 1-bit SPI 驱动不用 |

按用户照片所示的主板正面（天线朝上、USB-C 朝下、丝印朝自己），找主板**两侧**排针：左侧靠主控芯片的一列最上方是 `P4`，同列从上往下第 5 个是 `P8`；左侧远离主控芯片的一列最下方是 `P13`。右侧远离主控芯片的一列从上往下第 2 个是 `P41`、第 4 个是 `P47`；右侧靠主控芯片的一列第 5 个是 `P21`，第 6、7 个是 `3V3`。右侧远离主控芯片的一列第 6、7 个是 `GND`。以板上的丝印为最终依据，**不要把最下方 `5V` 排针当成 `3V3`**。

HREF、D1 不接；该模组与转接板使用自己的 24 MHz 时钟，SDK 将 XCLK 设为 `-1`，不从 XJWB03 另接 XCLK。GPIO4 与灵机板可选舵机冲突，GPIO8 与可选 MPU6050 冲突；本项目的舵机由 NodeHexa 板管理，因此不在灵机板使用这两个外设。

**通电验证顺序：**接线后，在未接 USB 前逐项核对 VCC↔3V3、GND↔GND 和八根信号线，用万用表确认 3V3 与 GND 没有短路。保留主板底部已接好的 LJX40 语音模块；摄像头线只接主板两侧带 `P数字`、`3V3`、`GND` 丝印的排针，不接语音模块的 `VCC` 或音频信号排针。当前板上已烧录 `CONFIG_APP_CAMERA_TEST=1` 的诊断固件，官方帧校验通过并连续获得新画面。用 `./lingji.sh capture <灵机串口>` 保存一帧到本机忽略目录，或用 `./lingji.sh preview <灵机串口>` 打开本机实时预览页。若后续出现 I²C 或帧超时错误，先核对转接板针脚和 FPC 方向。当前还没有验证人体坐姿识别，诊断固件也未同时接入云端语音 Agent。
